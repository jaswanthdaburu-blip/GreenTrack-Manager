==================================================
1. PROBLEM STATEMENT
==================================================

Organizations plant many trees as part of environmental and sustainability programs.

However, they often have difficulty tracking:

- Trees planted
- Tree species
- Plantation locations
- Tree health
- Survival status
- Survival rates
- Maintenance activities
- Trees requiring attention

Manual spreadsheets and records make it difficult to monitor trees and make data-driven decisions.

The proposed system should provide one centralized platform where organizations can manage all tree plantation information.

==================================================
2. EXPECTED OUTCOME
==================================================

Create an AI-powered full-stack system for organizations to track trees planted, locations, species, survival rates, and maintenance, while using AI to:

1. Analyze tree health
2. Predict tree survival chances
3. Recommend maintenance activities
4. Generate intelligent plantation insights
5. Identify high-risk trees
6. Provide an AI chatbot for organization data
7. Display all important information through an interactive dashboard

16. AI TREE HEALTH ANALYSIS
==================================================

Create an AI health-analysis feature.

User flow:

1. User opens tree details.
2. User uploads a tree/leaf image.
3. Image is stored in Supabase Storage.
4. Image is sent to AI service.
5. AI analyzes the image.
6. Result is saved to health_analysis.
7. Result is displayed to the user.

Return:

- Health status
- Possible issue
- Confidence score
- Recommended action

Example:

Health:
Needs Attention

Possible Issue:
Possible leaf disease symptoms

Confidence:
82%

Recommendation:
Inspect the leaves and check watering conditions.

IMPORTANT:
Clearly state that this is an AI-based assessment and not a guaranteed diagnosis.
